# Wardlight — notes for Claude sessions

Original single-player dark-fantasy wizard action-adventure for Mac (keyboard + trackpad).
Godot **4.7.1.stable** (a13da4feb), typed GDScript, Compatibility renderer, 640×360 viewport,
integer scaling, nearest filtering. All art/audio/font is original and generated by code in `tools/`.

- Original brief: `docs/brief.md`. Progress + agreed changes: `docs/checklist.md` (keep it updated).
- Where this file or the checklist disagrees with the brief, this file wins.

## Owner's decisions (do not undo)
- **Look: 3D world, 2D pixel characters.** Third-person diagonal-down camera (pitch 50°, fov 30,
  distance 25) over heightfield terrain with pixel-grid textures and dithered banded lighting;
  characters/props are pixel-art billboards (1 px = 1/24 m). Reference scene: `scenes/mockup3d.tscn`,
  rendering helpers in `game3d/`, gameplay in `game/`.
- **Side-facing sprites only.** No front/back character views. Sprites are upright Y-axis billboards
  (`game3d/sprite_lit.gdshader`); `Player3D.staff_tip()` mirrors that math.
- **No jumping.** Hills/slopes are walked. Levitation (float) is the only traversal ability.
- **Natural terrain only** — no floating or Mario-style platforms.
- Cross-relic recipes cut; same-relic tier fusion (I → II → III) kept.
- Home decor comes from thank-you gifts *and* coin purchases.
- Trackpad tap/hold (or J) = free staff attack; the cursor aims attacks and spells.
- Hat and beard appearance options. "People need you" story beats (named villager asks for help,
  rescued travellers reappear).
- Title: Wardlight. Git history stays in this repo only.

## Where things live
- World: `game/world/region.gd` (base: terrain, props, exits, checkpoints) and one script per place
  (`sanctuary`, `hearthmere`, `briarwood`, `old_ward`). World consequences go in `apply_state()`
  (runs every visit; must be idempotent).
- Progress: `GameState` autoload (flags, once-events, quests, unlocks, inventory, home, companion);
  `SaveSystem` autoload (versioned JSON, temp+verify+backup). Rewards use `GameState.once(id)`.
- Items: `game/items/items.gd` (definitions), `inventory.gd` (instances, equip, fusion).
- UI: `game/ui/*` (HUD, dialogue, journal, map, inventory, fusion, build mode, menus, settings).
- Scripted demos in `game/core/demo_driver.gd` (`story` plays the whole quest).
- Report and asset manifest: `docs/report.md`, `docs/assets.md`.

## Review gates
The owner approves feel and looks from screenshots/clips. Don't ship big visual or combat-feel
changes as "done" without showing captures; list what changed and wait for OK or changes.

## Commands
```bash
tools/dev/check.sh                    # import + parse-check every script/resource + rule tests
tools/dev/run.sh /tmp/x.log 90 --path . -- --demo=story --shots=/tmp/shots   # whole quest, scripted
godot --headless --path . --export-release "macOS" build/Wardlight.zip          # Mac build
godot --headless --path . --script tools/gen_art.gd   # regenerate art (then --import)
```
- New `class_name`s aren't visible until `godot --headless --path . --import` runs (check.sh does it).
- Scripted demos: `-- --demo=<name> --shots=<dir>` (see `game/core/demo_driver.gd` for the command
  list: hold/release/tap/aim3/tp3/pos/shot/quit…). `quit` prints `DEMO fps=`.
- GDScript: annotate types explicitly (`var x: Type = ...`) when inference is ambiguous — the checker
  treats inference failures as errors.

## Cloud sessions
Godot isn't pre-installed in cloud VMs. At the start of a cloud session run:
```bash
scripts/cloud_setup.sh
```
It installs Godot 4.7.1 (from this repo's `godot-4.7.1-stable` release), tries to add xvfb +
software OpenGL, and imports the project. Headless checks and tests work fully. Screenshots may work
via `xvfb-run -a godot --rendering-driver opengl3 --path . <scene> -- --demo=... --shots=...` but
render with software GL on Linux — fine for layout/logic sanity, **not** for judging final look,
lighting or performance (those are verified on the owner's M3 Mac). Commit to a branch and open a PR;
note anything that needs a visual check on the Mac.
