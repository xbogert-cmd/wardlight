# Wardlight

A dark-fantasy wizard adventure: a 3D world seen from a diagonal-down camera, with pixel-art
characters. Godot **4.7.1.stable** (official build
a13da4feb), Compatibility renderer, 640×360 pixel viewport with integer scaling.

## Run

- Editor: open Godot 4.7.1, *Import* → select this folder's `project.godot`, press ▶.
- Command line:

```bash
godot --path "/Users/alexanderbogert/wizard game"
```

## Controls (remappable later in Settings)

| Action | Keys |
| --- | --- |
| Move | W A S D (arrow keys also work) |
| Levitate (after the fawn) | Hold Space |
| Talk / use / contextual magic | E |
| Journal / world map | Q / M |
| Dodge | Shift |
| Staff attack (free) | Trackpad tap / left click, or J — hold to repeat |
| Spells | 1 2 3 4 |
| Aim | Move the cursor. Pointing at an enemy locks it (Assisted aim). With the mouse idle, spells target the nearest enemy in the direction you move. |
| Pause | Esc (also pauses when the window loses focus) |
| Debug overlay | F3 |

## Regenerating assets

All art and audio are original and generated by scripts in `tools/` (so they can be refined later):

```bash
godot --headless --path . --script tools/gen_art.gd      # enemies, icons, fx, 3D world textures
godot --headless --path . --script tools/gen_audio.gd    # sound effects and music loops
godot --headless --path . --script tools/gen_font.gd     # "Wardhand" pixel font
godot --headless --path . --import                       # let Godot import the new files
```

The wizard sprite sheet is built at runtime from the chosen appearance (`game/art/wizard_art.gd`).
