# Chapter 2 Step 3: Opening, Fenway, Reedhollow, Boat Travel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A finished Chapter 1 save opens Chapter 2 in Hearthmere (wounded Kess arrives), a waystone takes the wizard to the Fenway marsh road, which leads on foot to Reedhollow, the lake hub, whose boats will carry the wizard to the shrine areas (steps 5–8).

**Architecture:** Two new `Region` subclasses (`fenway.gd`, `reedhollow.gd`) built with the existing helpers plus three small `Region` additions: an `enemy_scale` applied in `spawn()`, a `base_y` option for `house()` (stilt houses), and two environment presets (`marsh`, `lake`). The quest `hollowing` lives in `Quests.DATA`; `Quests.current_main()` feeds the HUD and map. Travel reuses `Main.travel` + `Journey` (a boat variant for lake trips). Deep lake water is a hazard (like Briarwood's chasm): walk in and you're put back ashore, levitate across short gaps.

**Tech Stack:** Godot 4.7.1, typed GDScript, generated art (`tools/art/*`), generated audio (`tools/gen_audio.gd`).

## Global Constraints

- Kess can only join through the Chapter 2 opening (never in Chapter 1). The opening starts only when `dark_ward` is done and `hollowing` hasn't started.
- Camera rule: nothing taller than ~1.6 m between the camera (south) and a path or fight area. The lake and every tall structure in Reedhollow lie north of the walkways. Verify with screenshots.
- Chapter 2 enemies: +25% health and damage (`enemy_scale = 1.25`), set per region. Familiar enemies only in this step (Husks etc. arrive in step 4).
- Palettes: Fenway reed green + teal; Reedhollow warm lanterns over cold water.
- Existing checks must cover the new regions automatically (exit reachability iterates `Main.REGIONS`).
- `tools/dev/check.sh` passes after every task. Step 3 is a **(look)** gate: send captures, wait for the owner.

### Task 1: Quest, opening condition, enemy scale (logic + tests)

**Files:** `game/world/quests.gd`, `game/world/region.gd` (`enemy_scale`, `scaled_data`), `game/ui/hud.gd` + `game/ui/world_map.gd` (use `Quests.current_main()`), `tests/test_lake.gd` (new)

**Interfaces:**
- `Quests.HOLLOWING := &"hollowing"`, steps: 0 find out who came, 1 take a waystone to the Fenway, 2 follow the marsh road to Reedhollow, 3 relight the three shrines, 4 defend Reedhollow, 5 cross to the Heart Isle
- `static func Quests.hollowing_ready() -> bool` — `dark_ward` done and `hollowing` not started
- `static func Quests.current_main() -> StringName` — `hollowing` once started, else `dark_ward`
- `static func Quests.shrines_lit() -> int` — count of flags `shrine_chapel`, `shrine_mire`, `shrine_grove`
- `Region.enemy_scale := 1.0`; `static func Region.scaled_data(d: EnemyData, s: float) -> EnemyData` (copy with `max_hp` and `damage` × s; the original resource is untouched)

Tests (`tests/test_lake.gd`):

```gdscript
extends RefCounted
## Chapter 2's lake: opening condition, quest order, enemy scaling.

var t


func test_opening_only_after_chapter1() -> void:
	GameState.reset()
	t.check(not Quests.hollowing_ready(), "a new game can't start Chapter 2")
	GameState.start_quest(Quests.MAIN)
	GameState.advance(Quests.MAIN, 5)
	t.check(not Quests.hollowing_ready(), "not while Chapter 1 is running")
	GameState.advance(Quests.MAIN, -1)
	t.check(Quests.hollowing_ready(), "ready once Chapter 1 is done")
	t.eq(Quests.current_main(), Quests.MAIN, "the HUD still shows Chapter 1 until the opening")
	GameState.start_quest(Quests.HOLLOWING)
	t.check(not Quests.hollowing_ready(), "the opening plays once")
	t.eq(Quests.current_main(), Quests.HOLLOWING, "then the HUD follows Chapter 2")
	GameState.reset()


func test_shrine_count() -> void:
	GameState.reset()
	t.eq(Quests.shrines_lit(), 0, "none lit")
	GameState.set_flag(&"shrine_mire")
	GameState.set_flag(&"shrine_chapel")
	t.eq(Quests.shrines_lit(), 2, "any order counts")
	GameState.reset()


func test_enemy_scale_copies_data() -> void:
	var base: EnemyData = preload("res://data/enemies/hound.tres")
	var hp := base.max_hp
	var s := Region.scaled_data(base, 1.25)
	t.near(s.max_hp, hp * 1.25, "health scaled")
	t.near(s.damage, base.damage * 1.25, "damage scaled")
	t.near(base.max_hp, hp, "the shared resource is untouched")
```
